# Neonflow Landing Page - Build Plan

## Overview
Create a simple, clean landing page for neonflow.co that showcases our SaaS product portfolio. Professional but minimal since this is a holding company.

## Design Aesthetic
- Clean, minimal, modern
- Neutral color palette: whites, grays, maybe one accent color (subtle blue or green)
- Good typography hierarchy (Inter, system fonts, or similar)
- Plenty of white space
- Professional but not corporate-stuffy

## Content Structure

### Hero Section
- "Neonflow" as simple wordmark/text
- Brief tagline: "Building useful software" (or similar - 2-4 words max)
- Clean, minimal design - no fancy animations

### Apps Section
Simple card layout showing:

1. **Midweek** - "Church marketing, simplified"
   - Link: https://midweek.app (or # if not live)
   
2. **Rivvot** - "Form builder for modern teams"
   - Link: https://rivvot.io (or # if not live)

3. **More coming soon...** - Subtle placeholder

### Footer
- "© 2026 Neonflow. All rights reserved."

## Technical Requirements
- Single-page static HTML site (React component or plain HTML/CSS/JS)
- Fully responsive (mobile-first)
- Fast loading, minimal dependencies
- Simple hover states on cards (subtle)
- Optimized for deployment to Vercel/Netlify

## Interactive Elements
- Minimal hover effects on app cards (maybe slight shadow or border)
- Keep animations subtle or skip them entirely

## Do NOT Include
- Contact forms
- Email signup
- Social media links
- Complex navigation
- Blog section

## Tone
Think: clean portfolio page, not marketing site. Let the individual apps have personality - this is just a simple directory.

## Deployment Note
Output should be ready to deploy immediately to neonflow.co via Vercel or similar static hosting.
